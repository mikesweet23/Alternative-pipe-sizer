Assumptions

Component resistances use standard velocity-head factors (CIBSE C / Crane TP-410) rather than manufacturer data: butterfly 0.35, gate 0.15, strainer 2.5, regulating set 3.0, check 2.0. Control valves are sized to the authority target above. Replace with selected products before issue.
